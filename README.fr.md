# Le site Libre AI

Trouver le projet Libre AI qui répond à votre besoin et comprendre ce que vous pouvez en attendre.

Le site prévu s'adresse aux personnes qui découvrent Libre AI et souhaitent :

- explorer les produits à partir d'exemples d'usage ;
- distinguer les outils disponibles des projets en préparation ;
- accéder au bon projet pour en savoir plus ou contribuer.

## Où commencer ?

Ce dépôt présente le projet de site ; il ne contient pas encore de site à installer ou de service à ouvrir.

Pour découvrir les projets dès maintenant, consultez le [catalogue Libre AI](https://github.com/libre-ai/.github/blob/main/profile/README.fr.md).
