# Libre AI Project Website

## Intended use

Present the Libre AI offer and help a visitor navigate the portfolio by product purpose, actual capability state and supporting evidence. The website is a presentation surface; it does not grant authority to the products it describes.

## Existing candidates and limits

Earlier sources contain a static website candidate and local build work. This documentary candidate does not claim that the site is online, that all linked repositories are reachable or that described future products are usable.

## Proposed boundaries

Present admitted capabilities and future scopes distinctly, with bilingual descriptions and canonical repository names. Link factual claims to their applicable evidence without turning historical results into current deployment claims. Content and presentation do not replace Governance decisions or Contracts definitions.

## Activation criteria

Review bilingual product facts, navigation and evidence references. Qualify the selected static build and presentation behavior, including relevant accessibility and privacy observations. Public website activation additionally requires verified hosting, reachable final links and publication evidence. A bounded presentation module may be qualified independently; neither it nor this repository’s documentary existence requires a complete Missions journey.
