# The Libre AI website

Find the Libre AI project that fits your needs and understand what to expect from it.

The planned website is for people discovering Libre AI who want to:

- explore products through examples of their intended use;
- distinguish available tools from projects still being prepared;
- find the right project to learn more or contribute.

## Where to start

This repository describes the website project; it does not yet contain an installable website or a service to open.

To explore the projects today, visit the [Libre AI catalogue](https://github.com/libre-ai/.github/blob/main/profile/README.md).
